## Go CLI To-Do List App

A simple and interactive command-line To-Do list app built using Go. Easily add and manage tasks directly from your terminal! 

---

##  Features

- Add tasks from the command line
- View all tasks with status
- Simple, clean CLI interaction
- Tasks stored in memory (for now — file persistence coming soon)

---

## ⚙ How to Run

1. Clone or download this repository
2. Open your terminal and navigate to the project folder
3. Run the app:

**For bash** 
go run main.go
